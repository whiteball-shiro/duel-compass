# Security

Run on a trusted local computer. The MCP exposes local file access and state-changing deck/duel operations; configure only trusted clients. The engine binds to loopback and rejects browser-origin requests. It is not a multi-user service or a security boundary against programs running as the same OS user. Do not expose its port through a public proxy or tunnel.

Downloaded data and scripts come from external community sources. Use trusted sources and keep dependencies current. Never commit credentials, personal replays or learned strategies. Report security concerns privately through GitHub security reporting when available, or contact the owner without publicly sharing secrets or exploit details.
