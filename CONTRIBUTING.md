# Contributing

Use Node.js 22 or 24, npm ci and npm test. Default tests must be independent of downloaded card databases. Keep live checks in explicitly enabled integration tests. Add regression tests for substantive bugs, distinguish official and community evidence, preserve notices and do not commit personal records or downloaded data.

For UI changes verify complete effects, LINK/Rank fields and multi-card batches. For retrieval verify identities, provenance, freshness, pagination and offline fallback. Describe validation and external dependency limits in pull requests.
