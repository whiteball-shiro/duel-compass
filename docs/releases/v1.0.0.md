# Duel Compass 1.0.0

首次安装从基础版 ygo-ai 的固定 GitHub 提交取得配套卡库、禁限表、字符串和卡片脚本。新用户无需自行准备卡库，也不再需要连接卡库 CDN 才能完成首次初始化。

```sh
git clone https://github.com/whiteball-shiro/duel-compass.git
cd duel-compass
npm ci
npm run data:init
```

需要 Node.js 22 / 24 和 Git 2.25 或更新版本。完成后按 README 配置 MCP 客户端。

- 锁定源提交并验证 SQLite 内容和引擎基础脚本，整批资料验证后安装。
- 保存资料来源，重复初始化保留已有卡库，不覆盖用户后续更新。
- CDN 仅用于之后明确请求的数据刷新。
- 原有本地导入方式继续可用，但不再是新用户必须使用的备用安装流程。

已在完全空白的数据目录完成 GitHub 在线初始化，取得 14,820 条基础数据库记录和配套脚本，随后 50 项完整测试全部通过。规则资料也完成在线初始化。自动检查新增 Windows / Linux、Node 22 / 24 下的全新安装与真实资料集成验证。

项目保持社区工具定位；固定版本的基础资料不代表实时最新卡库或禁限表。最新卡片和适用地区禁限状态仍需按需求更新核实。原有版权、第三方许可和资料使用边界保持不变。
