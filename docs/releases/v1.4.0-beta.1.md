# Release notes — v1.4.0-beta.1

Duel Compass / 决斗罗盘首个独立预览版本，基于 inoribea/ygo-ai 扩展，保留上游版权与第三方 MIT 许可。

- 完整卡文与同批多卡展示，修正连接怪兽的 LINK / DEF 字段。
- OCG 规则、问答、FAQ 检索，区分来源、时效、镜像和摘要。
- 卡组身份绑定的策略学习与录像复盘。
- 独立用户数据目录、锁定依赖、资料初始化和本地导入。
- 引擎限制回环访问，拒绝浏览器来源请求。

源码与安装包不包含完整卡库、官方问答快照、卡图、个人录像和学习记录。

验证：Windows，Node.js 22 与 24，47 项测试全部通过；安装包在新目录安装后，17 个工具可用，莱娜四张异画完整卡文可读，规则状态正常。依赖审计未报告已知漏洞。Linux / Windows CI 已配置，实时结果可在仓库 Actions 页面查看。

已知限制：卡库 CDN 在当前网络环境中重复中断，自动下载无法保证；已验证从兼容本地数据目录导入的备用流程。规则资料在线初始化成功。YGOPro2 / WindBot 需自行安装配置，未打包相关二进制。本项目为社区工具，检索与引擎输出不能替代官方裁定。
